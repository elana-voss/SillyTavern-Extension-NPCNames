Use the `suggest_npc_name` tool whenever you are about to introduce a new NPC into the story: anyone with a name who is not {{user}}, not yourself, and not someone already named earlier in this chat. Do NOT invent the name yourself. The tool returns a single curated first and last name from a tagged database that the user has tuned for variety. Relying on your own naming instincts produces the same handful of names ("Elara", "Marcus", "Aria") over and over.

Pass the filters that matter for this character. Every filter is optional. You may pass none, some, or all. The richer the filter set, the more on-tone the result.

- `gender`: male, female, ambiguous.
- `language_ethnicity`: the cultural root of the name. Real-world buckets for human characters (e.g. english, japanese, slavicRussian, arabic, finnish, yoruba). Fantasy buckets for non-human races: fantasyElvish, fantasyDwarven, fantasyDragon. If you want an elf, pass `race: elf` and the tool will pick a fantasyElvish first name automatically.
- `mythology`: tag from a named pantheon if the character should evoke it: celtic, egyptian, greek, hindu, japanese, lovecraft, mesopotamian, nativeAmerican, norse, roman, slavic.
- `race`: human, elf, dwarf, dragon.
- `age`: the lifestage the name fits: child, youngAdult, adult, elder.
- `era`: the period the name evokes: ancient, victorian, nineteenTwenties, midcentury, modern, contemporary, nearFuture, timeless.
- `role`: narrative function: hero, villain, mentor, sidekick, comicRelief, loveInterest, antihero, neutral, bystander.
- `intelligence`: how cerebral the name sounds: blunt, plain, average, thoughtful, bookish.
- `allure`: how attractive the name sounds: harsh, unremarkable, pleasant, pretty, striking.
- `commonness`: common, uncommon, rare.
- `genre`: the story's flavour: fantasy, cyberpunk, steampunk, western, noirDetective, horror, sliceOfLife, postApocalyptic.
- `themes`: zero or more decorative tags: airy, brutish, celestial, earthy, exotic, fiery, floral, gemstone, icy, literary, lunar, military, mystical, regal, religious, rustic, scholarly, solar, watery.

The response is a flat JSON object with snake_case keys. Weave `first_name` and `last_name` into your narration naturally. The other fields describe how the database classified the name. Treat them as soft prompts to colour the character's voice, demeanor, and feel:

- `age` (array), `era` (array), `role` (array) often hold multiple values because the same name plausibly fits multiple lifestages, periods, or archetypes.
- `intelligence` and `allure` describe how the name itself sounds (phonetics and cultural connotation), not the bearer's actual traits.
- `commonness` says whether the name is everyday (`common`), somewhat known (`uncommon`), or distinctive (`rare`).
- `genre` and `themes` are zero-or-more arrays. Empty is normal when none of the values fits.
- `mythology` is present only for names tagged to a pantheon.
- `relaxed_filters` is present when the tool dropped some constraints because no name matched the full combination. The returned name still fits the remaining filters but not the relaxed ones. Mention the relaxation only if it changes how you describe the character.
- The `last_name_*` keys (`last_name_role`, `last_name_allure`, `last_name_commonness`, `last_name_genre`, `last_name_themes`) describe the surname separately. Surnames carry their own role coding (Blackwood reads villain) and allure (Featherstonehaugh reads sophisticated). They do not carry intelligence, age, or gender.

The same name will not be returned twice in this chat. Call the tool once per new NPC. Do not call it for the player character, your own character, or anyone already named in the chat.
